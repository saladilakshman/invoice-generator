# Invoice Generator App
This Invoice Generator App is built using ReactJS and Tailwind CSS. The app allows users to generate invoices, share them, and save them as PDF using the html2pdf library. It also uses LocalStorage API for storing invoice data.

## Features
- Invoice Generation: Create detailed invoices with customizable fields.
-Share Functionality: Users can share the generated invoices.
- Save as PDF: Download invoices as PDF using html2pdf.
- Local Storage: Stores invoice data locally for later use.
- Responsive Design: Ensures a seamless experience across all devices, including desktops, tablets, and mobile phones.


## Technologies Used
* **ReactJS** : For building the user interface.
* **Tailwind CSS** : For a modern and responsive design.
* **html2pdf** : For converting HTML invoices to PDF.
* **Local Storage** : For storing invoice data locally.

## Installation
1. Clone the repository:

    ````bash 
    git clone https://github.com/saladilakshman/invoice-generator.git
   ````

2. Install dependencies:

    ```bash
    npm install
    ```



3. Start the development server:

    ```bash
    npm run dev
    ```

5. Open your browser and navigate to `http://localhost:5173`.
